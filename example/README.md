# logging_flutter example

This Flutter app demonstrates the `Flogger` methods, logs from Dart's `logging` package, and the in-app `LogConsole`.

From this directory, use the Flutter version in `.fvmrc`:

```sh
fvm flutter pub get
fvm flutter run
```

The example supports Android and iOS. Its `logging_flutter` dependency points to the parent directory so local package changes are visible immediately.
